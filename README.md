🦅 Eagle Store – E-Commerce Website
📌 Project Description

Eagle Store is a frontend e-shopping website designed to allow users to browse and order products online.
The website sells items such as clothes, shoes, watches, and other fashion accessories.

The project is built using HTML and CSS only and focuses on user interface design and page layout.
There is no user login, no backend, and no database integration.


🛍️ Products Offered

Clothes 👕
Shoes 👟
Watches ⌚
Other fashion accessories

🌐 Website Pages

The website contains the following pages:
Home Page – Introduction and featured products
About Page – Information about Eagle Store
Products Page – Display of available items
New Arrivals Page – Latest products in the store
Contact Page – Contact details and inquiry form

🚚 Ordering & Payment Information

Users can order products without creating an account

Home delivery is available
Payment options include:
Mobile Money (MoMo Pay)
Airtel Money
Bank payment
Pay on delivery (cash after product arrives)

⚠️ Payment options are for UI display purposes only (no real transaction processing).

🛠️ Technologies Used

HTML5 – Website structure

CSS3 (Plain CSS) – Styling and layout

No JavaScript framework, backend, or database is used.


🚀 How to Run the Project

Download or clone the project repository

Open index.html in any modern web browser

🎯 Purpose of the Project

Practice frontend web development

Improve HTML & CSS skills

Create a simple e-commerce UI design

Use as a school or portfolio project

🚫 Limitations

No backend functionality

No real payment processing

No user authentication or login

Orders are not stored in a database
